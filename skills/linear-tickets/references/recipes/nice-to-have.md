# Recipe: Nice to have

A genuinely optional, deferrable enhancement — captured so it isn't lost, but
explicitly low-priority. Label `Nice to have`, **Priority: Low**.

Keep it lightweight — a nice-to-have doesn't warrant a full contract or exhaustive
AC. But it must still be *actionable later*: a future reader should understand the
idea and roughly what "done" means without more context from you.

## Minimum viable body

```markdown
## What
The idea and the value it would add. Note it's optional / deferrable and what
prompted it (link the parent feature or the discussion).

## Scope (rough)
A few bullets — enough to size it later.

## Acceptance criteria
Loose but testable: the one or two things that would make this "done" if picked up.
```

## Notes

- If it turns out to be blocking or clearly valuable, it's probably a Feature or
  Improvement — reclassify rather than mislabel.
- Set a parent epic if it belongs to one, so it surfaces when that area is revisited.
- Don't over-invest: the point is a low-cost capture, not a polished spec.
